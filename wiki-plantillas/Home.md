## Equipo y liderazgo de los ejercicios de *tailoring*

Cada uno de los cinco integrantes debe liderar y poder defender **un**
ejercicio completo de *tailoring* (ISO/IEC/IEEE 12207 y CMMI). Los
ejercicios son: Paso 5, Paso 6 y los tres procesos mínimos del Paso 7.
Registren aquí el reparto antes de empezar.

| Integrante (usuario de GitHub) | Ejercicio de *tailoring* que lidera |
|---|---|
| | Paso 5 — gestión de riesgos |
| | Paso 6 — estimación, cronograma y presupuesto |
| | Paso 7 — proceso 1: |
| | Paso 7 — proceso 2: |
| | Paso 7 — proceso 3: |
